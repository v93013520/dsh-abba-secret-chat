# AB-BA 秘密对话 · dsh-abba-secret-chat

装进 **DeepSeek Harness** 右侧栏的一次性双人密码聊天：A、B 各自定一个密码、互相告诉对方，**两个密码都填对**才配对成功；消息只在内存里转发，不落盘、不写日志；聊天页由本机的局域网小服务提供，**关掉 DSH 就一起消失**。

[English](README.md) | 中文

![右侧栏里的双人对话](docs/screenshots/01-sidebar-chat.png)

*左侧栏底部多了「秘密对话」入口，聊天页开在主对话旁边的右侧栏里，主对话框完全不受影响。*

## 它解决什么问题

想和身边的人（同事、家人、朋友）临时说几句私密的话，又不想注册账号、不想留聊天记录、不想把内容混进 AI 会话——两个人各自知道一个密码，在 DSH 里点一下就能开一间「碰头才存在」的聊天室，聊完即焚。

## 功能

- **右侧栏聊天**：左侧栏底部有一个 **🔒 秘密对话** 入口按钮（窄侧栏只显示图标），点击后在**右侧栏**打开「秘密对话」tab，聊天页嵌在 tab 里；也可以从右侧栏「+」新建页的入口卡片打开。主对话框照常用，两边互不干扰。
- **双密码配对**：A 框填 A 的密码、B 框填 B 的密码，两处都正确才会进入同一个房间；**两个框填反也能配上**（房间钥匙与顺序无关，免得因为记错顺序连不上）。
- **同一组合只容两人**：第三个人填同一组密码会被明确拒绝；任何一方退出、刷新、断网，房间立即销毁、双方内容同时清空。
- **只在内存里转发**：服务器只做 A → 服务器 → B 的转发，不存消息、不写日志、不落盘；进程退出即全部消失。
- **局域网可用**：默认在本机 `8787` 端口起一个只有几个接口的小服务，并绑定局域网地址；对方在同一 Wi-Fi 下用浏览器打开「对方链接」就能加入，**对方什么都不用装**。端口被占用时依次回退 `+1…+9`，还不行就交给系统分配；实际端口会显示在面板工具条和 `/abba` 状态里。
- **零依赖、免构建**：不引入任何 npm 运行时依赖，没有构建脚本与 `postinstall`，安装快、审计简单；MIT。
- **随 DSH 生命周期**：聊天服务是 DSH 进程里的一个插件组件，DSH 退出/插件卸载时自动关闭；没有常驻后台进程。

## 安装

要求 **DeepSeek Harness `>= 0.2.1-rc.3`**（`engines.dsh`；0.2.1 之前的宿主没有右侧栏与 `sidebarRight` API）。

**A. 已上架后：市场安装（推荐）**

DSH → 左侧栏 **插件** → **插件市场** → 搜 `dsh-abba-secret-chat` → 安装。

**B. 桌面端从本地目录安装（当前开发版适用）**

DSH 桌面端 → 左侧栏 **插件** → **安装** → 选择「本地目录」→ 填本包所在目录 → 安装；安装后**完全退出并重开 DSH**。

**C. 命令行（普通 `dsh web` 或自建 profile）**

```powershell
dsh plugin --profile web add dsh-abba-secret-chat
# 还没有 npm 映射时，也可以直接装源码：
dsh plugin --profile web add github:v93013520/dsh-abba-secret-chat
```

> 桌面端 profile 由桌面应用自己的插件管理器管理，不要手改 `profiles/desktop`；桌面端请走应用内的插件页安装。

安装/更新后重启 DSH，新插件才会载入。

## 使用三步

1. **约定密码**：A 和 B 各自想一个密码（4–128 个字符），通过微信/口头等**聊天之外**的渠道互相告诉对方。
2. **双方加入**：A 点左侧栏底部「秘密对话」→ 在右侧栏的 A 框填 A 的密码、B 框填 B 的密码 → 「开始碰头」，进入等待；B 拿到 A 的**对方链接**（面板工具条上那一条 `http://192.168.x.x:8787`），在同一 Wi-Fi 下用浏览器打开，用同样两个密码加入（填反也行）→ 两人自动配对。
3. **聊天与结束**：回车或「发送」实时收发；任何一方点「结束聊天」（或直接关页面/刷新）→ 会话立即销毁，两边内容同时清空。发起人等待 10 分钟无人加入会自动取消。

> 想自己先走一遍？在同一台电脑开两个浏览器标签都打开 `http://127.0.0.1:8787`，一个当 A、一个当 B 即可。

## 命令

在 DSH 输入框发送：

| 命令 | 作用 |
|---|---|
| `/abba` | 查看运行状态、本机地址、局域网地址与入口提示 |
| `/abba status` | 同上 |
| `/abba stop` | 停止聊天服务（右侧栏聊天页随之不可用） |
| `/abba 9000` | 停掉旧服务，改用 9000 端口重启（同样有回退） |

## 配置（可选）

本插件没有 UI 设置页；如需改端口或只允许本机访问，在 profile 的 `cordis.patch.yml` 里覆盖该行的 `config`（注意 patch 会替换整行的整个 `config`）：

```yaml
- id: abba-secret-chat
  name: dsh-abba-secret-chat
  config:
    port: 9000        # 默认 8787；被占用会回退 +1..+9
    host: 127.0.0.1   # 默认 0.0.0.0（局域网可达）；只允许本机时改成这个
```

## 隐私与安全

- **只在内存**：房间、成员、消息都在进程内存的 `Map` 里，进程退出即消失；服务器不写数据库、不写文件、不记录消息内容，也不写消息日志。
- **不碰浏览器存储**：聊天页不使用 Cookie / localStorage / sessionStorage；客户端标识只存在于当前页面内存。
- **双密码**：两个密码只以 SHA-256 哈希的形式在内存中参与房间钥匙计算，不落盘、不回传、不写日志。
- **明文 HTTP**：聊天页走局域网上的明文 HTTP（默认 `0.0.0.0:8787`）。请只在可信网络（家庭/办公局域网）里使用；跨公网请自备 HTTPS 反向代理。**知道这两个密码的人都能加入。**
- **与 DSH 会话隔离**：聊天页是独立服务提供的一张网页，聊天内容不进入 DSH 会话、不会交给模型；插件也没有注册任何模型工具。
- **生命周期**：聊天服务随 DSH 进程启停，没有常驻后台进程、不写系统服务。

